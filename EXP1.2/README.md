# Draft Manager

A simple React frontend draft management system built in `EXP2`.

## Features
- Create, edit, and delete drafts
- Search/filter drafts with memoized selectors using `reselect`
- Mock API load simulation
- Draft summary analytics

## Run locally

1. Open terminal in `c:\Users\BIMAL\Desktop\fsd2\EXP2`
2. Run `npm install`
3. Run `npm run dev`

Then open the local Vite URL shown in the terminal.
